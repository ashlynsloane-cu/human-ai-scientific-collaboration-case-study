# Phase 5: preliminary corpus-eligibility adjudication

This phase implements **step 1** in the frozen protocol's coding order: determine which source conversations are materially related to the Hsp60/10 project. It is not an intervention coding study and changes none of the V1 definitions.

## Current status

- Reviewed a **stratified and enrichment-augmented, 140-distinct-conversation pilot**, not a census of 1,049 conversations.
- Source-based, provisional first-pass decisions: 69 include, 63 exclude, 8 uncertain.
- All 140 case-level records have mainline source-node IDs, content fingerprints and individual rationales **only in the private local ledger**.
- Source pointers and text digests were re-verified against the original export for 140/140 records (automated integrity check, not independent scientific validity).
- The first-pass reviewer was an AI assistant; independent human coding is not complete.
- All E0–E5 exposure assessments, alternative branches, unavailable image/file contents, event coding and artifact propagation remain open.
- One source-specific manuscript-revision conversation was provisionally included from the originally unscreened probability-pilot stratum. This demonstrates at least one prior false negative but **does not estimate population false-negative rate**.

### Critical separation

**Pilot screening decisions are not final corpus membership.** The full project includes hypothesis generation, cell-based experiments, bulk/single-nucleus RNA-seq, TMT proteomics, statistical analysis, debugging, figure development, biological interpretation, and peer review/release. A conversation can discuss ROSMAP while belonging to a separate AREA rotation project; shared dataset names are not sufficient for inclusion.

Read `methods_and_limits.md`, `adjudication_resolution_plan.md`, and the frozen `protocol/protocol_v1.0.md` before using these results.
