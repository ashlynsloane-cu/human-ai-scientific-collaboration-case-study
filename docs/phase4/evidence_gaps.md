# Full-project coverage and evidence gaps

This is an evidence inventory, **not a scorecard of AI versus human contributions**.

| Workstream | Evidence currently available | Key unresolved question |
|---|---|---|
| Hypothesis & mechanism | Account export; early project conversations | Which ideas arose independently or from papers, coworkers or other AI sessions? |
| Wet-lab plans & controls | Account export; discussion of HSPE1 and MIC experiments | Which experiments were actually conducted? Lab notes and dates still needed. |
| Dataset and preprocessing | Account export; later R analysis repository | Are historical versions and run-specific transformations available? |
| Statistical analysis | Conversation proposals; scripts and reviewer revision code | Which AI proposals were executed, revised, rejected, and validated? |
| Coding & debugging | Chat-derived code guidance; current/public Git history | Does the publication repository preserve pre-release history and Codex actions? |
| Figures and results | Figure documents; sources and outputs in analysis repo | Which intermediate versions correspond to each conversation-level decision? |
| Biological interpretation | Conversation messages and manuscript versions | Which shifts were supported by new analyses and which were editing-only? |
| Manuscript and reviewers | June submission and October/November versions/response documents | Are the dated versions exactly submitted, and what changed in code contemporaneously? |
| Reproducibility and release | Git repository, README, validation documentation | Can private controlled-access data be used by an authorized party to rerun the pipeline? |
| Off-platform collaboration | Not yet collected | Were there additional AI assistants, research discussions, notebooks, Slack/email, and lab/PI decisions? |

**Scope distinction:** This study may eventually describe every recoverable interaction in one exported ChatGPT account. That is not the same as every AI interaction or every scientific decision in the entire Hsp60/10 project.
