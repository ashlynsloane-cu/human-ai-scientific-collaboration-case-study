# Full-project scope and artifact-linkage plan

This phase explicitly includes hypothesis generation, experimental planning, data and statistical methods, code, figures, interpretation, manuscript, peer review, and reproducibility. The manuscript is only one downstream source of evidence.

Files:
- `full_project_scope.md`: entire-project stages and complementary primary/secondary evidence streams.
- `attribution_and_linkage.md`: attribution rules, evidence ladder, and workstream corroboration.
- `../../data/phase3/full_project_workstream_register.csv`: ten-stage register, statuses all unvalidated.
- `../../results/phase3/source_coverage_summary.json`: counts of local supporting files, without identifying information.

All private source anchors and filenames are omitted by design.
