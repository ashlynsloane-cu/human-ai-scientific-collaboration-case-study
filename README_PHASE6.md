# Phase 6: Full-universe corpus recall audit (pre-coding)

- This is a versioned, **post-pilot high-recall discovery expansion**, not a finalized eligibility census.
- The private Phase 5 human/AI labels and three-case adjudication overlay are read and verified but not overwritten.
- All 1,049 exported conversations are processed with manifest byte verification and original Phase 4 SHA-256 checks.
- The remaining 909 conversations are indexed for full-context review: 200 originally screened and 709 originally unscreened.
- The 709 are ranked for *review priority only* using text similarity to provisionally included project chats. Rankings do not assert project relevance.
- An 80-case probability sample (20 per similarity quartile) is drawn from the 709 remaining originally unscreened conversations. It has not been reviewed or classified. Full-context source review, including available attachments, is required.
- Current mainline text and metadata are indexed; attached files, embedded visuals, and alternate-branch content are not comprehensively adjudicated. Exposure class E5 remains unassessed.

**Do not publish** the private queues; they contain personal-account conversation identifiers, titles and verbatim source snippets. Only scripts, synthetic tests, method notes and source-free aggregates belong in the public repository.

Usage and limitations: `docs/phase6/README.md`.
