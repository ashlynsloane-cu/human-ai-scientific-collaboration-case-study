## Corpus status

`data/conversation_corpus_candidates_v0.2.csv` contains the current candidate conversation corpus reconstructed from account-level retrieval across January–November 2026.

These are **candidate records**, not a claim of exhaustive coverage. Topic labels are reconstructed and should not be represented as original chat titles unless verified against an export.

The protocol requires a complete account export or equivalent exhaustive corpus audit before reporting "all project conversations."
