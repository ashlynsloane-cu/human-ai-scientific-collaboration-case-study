# Phase 24 — Scientific decision coding feasibility pilot (not production coding)

Purpose: calibrate the frozen V1 human-steering coding framework before exhaustive event extraction.

- Analysis frame: the previously qualified-frozen 245-conversation ChatGPT-export corpus; **not amended**.
- Pilot: 15 purposively selected conversations across five workflow strata (4 early hypothesis, 4 computational analysis, 3 figures/interpretation, 3 manuscript/peer-review, 1 reproducibility/release).
- Extracted evidence: 1,031 visible current-branch user/assistant text messages, including 464 user messages.
- Initial qualitative review: 16 handpicked, source-anchored examples for checking coder interpretation. **Not** exhaustive event identification or a representative sample.
- Integrity: all 11 original source-shard SHA-256 fingerprints matched the previously frozen sources, and all selected conversations linked to the frozen inclusion roster.
- Private supporting files are **not** part of this public package. Never commit source transcripts, conversation IDs, message IDs or the frozen private inclusion roster.

The **scientific steering event** remains the V1 primary unit. The proposed **atomic decision-opportunity inventory** is an *additional*, unadopted denominator candidate. No primary method was silently altered. Agreement metrics, steering-event rates, attribution percentages, implementation/propagation, and causal effect estimates have **not** been calculated.

Proceed after adopting and versioning appropriate operational clarifications, independent second-coder detection/segmentation checks, and a held-out validation plan. Do not use the 16 handpicked examples for prevalence inference.
